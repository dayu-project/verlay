# 映证 Verlay Chrome 扩展本机 Codex 版 0.4.0

这个版本让浏览器里的映证面板连接本机 Codex，并直接修改 VS Code 当前打开的网页项目。无需公网服务，也无需在插件里填写 API Key。

## 安装插件

1. 完整解压 ZIP。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后的目录，并把“映证 Verlay”固定到工具栏。

## 安装 VS Code 扩展

1. 打开 VS Code 的扩展页面。
2. 点击右上角“…”菜单，选择“从 VSIX 安装…”。
3. 选择安装包里的“映证-Verlay-VSCode扩展.vsix”。
4. 按提示重启扩展。

## 每个项目的启动方式

1. 使用 VS Code 打开要修改的网页项目，确认 Codex 已登录。
2. 点击 VS Code 底部状态栏的“启动映证”。
3. 第一次选择已运行的网页端口，或让扩展自动运行项目的 dev 脚本。
4. 映证会在 Google Chrome 中自动打开；以后会记住当前项目的启动方式。

无需打开终端，也无需另行安装 Airship CLI。映证只会把当前 VS Code
项目作为 Codex 的修改目录。

## 使用

1. 用 Chrome 打开项目的本地网页。
2. 点击映证图标打开编辑面板。
3. 选择页面元素，输入修改要求并发送。
4. Codex 写入项目源码后，VS Code 会自动显示文件变化，开发服务器通过 HMR 更新网页。

面板收起时不会拦截网页点击；重新展开后元素编辑恢复生效。
