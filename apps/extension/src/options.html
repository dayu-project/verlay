VERLAY LOCAL CODEX BRIDGE

连接本地 Codex 与 VS Code 项目

无需公网服务。Codex 会直接修改 VS Code 当前打开的同一套源码。

1

打开项目

使用 VS Code 打开网页项目，并安装“映证 Verlay”VS Code 扩展。

2

启动本机连接

点击 VS Code 底部的“启动映证”。第一次选择已运行的网页端口或项目 dev 脚本，以后会自动记住。

扩展会把当前 VS Code 项目作为唯一修改目录；不需要打开终端，也不需要安装 Airship CLI。

3

开始可视化修改

连接成功后，打开本地网页并点击映证图标。面板收起时不会拦截网页点击。

本机连接地址：127.0.0.1:5175
