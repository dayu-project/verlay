# 映证 Verlay 测试环境安装包

本安装包只包含映证新版 UI，用于团队内部测试。画板直接挂载在当前测试 Web 页面上，不会跳转到开发者电脑上的其他项目。

## 使用条件

- Chrome 116 或更高版本。
- Node.js 22 或更高版本。
- 测试人员电脑上有待修改 Web 项目的代码仓库。
- 已安装并登录 Codex CLI，或者已经配置可用的 Codex 认证。
- 首次运行本地助手需要联网安装其 npm 依赖。

## 一、安装 Chrome 扩展

1. 解压 `浏览器扩展/映证-Verlay-Chrome扩展-v0.1.1.zip`。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载未打包的扩展程序”。
5. 选择刚解压出来、内部直接包含 `manifest.json` 的目录。
6. 将“映证 Verlay”固定到工具栏。

## 二、启动测试 Web

按照项目原本的方式启动测试 Web，并记录浏览器地址中的端口。例如：

- `http://localhost:8080` 的端口是 `8080`。
- `http://localhost:3000` 的端口是 `3000`。

## 三、启动映证本地助手

### macOS

双击 `安装与启动.command`。如果系统阻止首次打开，可右键文件选择“打开”。

### Windows

右键 `安装与启动.ps1`，选择“使用 PowerShell 运行”。

启动脚本会要求填写：

1. 当前测试 Web 的端口。
2. 测试 Web 本地代码仓库的绝对路径。

服务成功启动后会监听：

`http://127.0.0.1:5175`

## 四、打开映证

回到已经打开的测试 Web 页面，点击 Chrome 工具栏中的“映证 Verlay”图标。新版编辑画板会直接显示在当前页面上；再次点击图标即可关闭。

## 重要说明

- 浏览器扩展负责界面、元素选择和修改预览。
- 本地助手负责 Codex、源码读写、Git 和测试。
- 每位测试人员都必须把本地助手指向自己的测试 Web 端口和自己的代码仓库。
- 如果只安装 Chrome 扩展而不启动本地助手，画板可以打开，但 Codex 和源码保存功能不可用。
- 不要把本地助手端口暴露到公网。
