# Figma v1.2 UI

This directory contains the current Figma-based Airship UI, including the
updated design inspector, confirmation action, and Figma icon assets.

## Preview

Run these commands from this directory in two terminals:

```sh
corepack pnpm dev:web-preview
corepack pnpm dev:preview
```

If the Muses target is already running on port 4173, only run `dev:preview`.

Open <http://localhost:5174/#apps> for the new UI. It previews the Muses apps
page at <http://127.0.0.1:4173/#apps>. The localized original UI remains at
<http://localhost:5175/#apps>.
